# Google Apps Script สำหรับรับประวัติซ่อม ATV Service Hub

ไฟล์ `RepairLogWebApp.gs` ถูกตั้งค่าให้ใช้กับ Google Sheet นี้แล้ว:

`https://docs.google.com/spreadsheets/d/1aZVFSY2sx2Qsog-6E_0oGStpYVtGaP-vKBhsMhxSsyA/edit`

## วิธีติดตั้ง

1. เปิด Google Sheet ตามลิงก์ด้านบน
2. ไปที่ **Extensions → Apps Script**
3. ลบโค้ดเดิม แล้ววางเนื้อหาจาก `RepairLogWebApp.gs`
4. กด Save
5. เลือก **Deploy → New deployment**
6. เลือกประเภท **Web app**
7. ตั้งค่า **Execute as: Me**
8. ตั้งค่า **Who has access: Anyone**
9. กด Deploy และอนุญาตสิทธิ์ให้สคริปต์เข้าถึง Google Sheet
10. คัดลอก URL ที่ลงท้ายด้วย `/exec`
11. เข้าเว็บ ATV → **โมดูลช่าง → ตั้งค่า → ตั้งค่าการส่งข้อมูล Google Sheet**
12. วาง URL `/exec` แล้วกด **บันทึก URL**

ห้ามนำลิงก์ `docs.google.com/spreadsheets/...` ไปใส่ในช่องของแอป เพราะแอปต้องส่งข้อมูลไปยัง URL ของ Apps Script Web App แทน

## ข้อมูลที่รับ

สคริปต์ตรวจสอบและรับข้อมูลครบ 13 คอลัมน์ตามลำดับนี้:

1. รหัสรายการ
2. วันที่และเวลา
3. วันที่แก้ไข
4. เวลาซ่อมรวม
5. เบอร์รถ
6. รายละเอียด
7. อะไหล่เบิกซ่อม
8. ชื่อช่างผู้ทำรายการ
9. ชั่วโมงสะสม
10. สถานะ
11. ตัวเลือก
12. รหัสแจ้งซ่อมจากไกด์
13. ประเภท

สคริปต์จะเปลี่ยนวันที่ ISO ให้เป็นรูปแบบ `วัน/เดือน/ปี ชั่วโมง:นาที:วินาที` ตามเวลาไทย และปรับข้อความสถานะให้คนอ่านเข้าใจง่ายขึ้น

## การทดสอบ

เปิด URL `/exec` ในเบราว์เซอร์ หากติดตั้งถูกต้องจะเห็นข้อความ JSON ว่า:

`Google Apps Script พร้อมรับข้อมูลแล้ว`

ในหน้า Apps Script สามารถเรียกฟังก์ชัน `testWriteRepairLog_()` เพื่อเขียนข้อมูลตัวอย่างหนึ่งแถวได้ หากไม่ต้องการข้อมูลตัวอย่าง ให้ลบแถวทดสอบออกก่อนใช้งานจริง

เมื่อแอปส่งข้อมูลสำเร็จ สคริปต์จะตอบกลับ `ok: true` จากนั้นแอปจึงจะล้างประวัติที่ส่งแล้ว ถ้าส่งไม่สำเร็จ แอปจะเก็บประวัติไว้ ไม่ล้างข้อมูล
